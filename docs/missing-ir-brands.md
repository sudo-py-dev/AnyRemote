# Missing IR brands

This inventory lists brands with public IR data and no matching catalog entry in the corresponding AnyRemote category. Each link points to one example file. Check the model, protocol, button coverage, and source license before adding a profile.

Brand matching ignores case, accents, spacing, and punctuation and accounts for common aliases. Set-top and cable/satellite boxes are compared together. Brand presence does not imply model coverage.
